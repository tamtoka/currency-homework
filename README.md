# Курсы валют

Консольная программа показывает курсы RUB, EUR и GBP для выбранной базовой валюты и переводит суммы между доступными валютами.

## Запуск в PowerShell

Понадобится Python 3.10 или новее. Выполните команды из папки с `currency.py`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe currency.py
```

На первом запросе нужен интернет. Файл `currency_rate.json` создаётся в текущей папке. Пока ему меньше 24 часов и его `base_code` совпадает с выбранной базой, приложение использует сохранённые курсы. При выборе другой базы файл обновляется после успешного запроса.

Нажмите Enter на первом приглашении, чтобы выбрать USD. Когда программа спросит, из какой валюты перевести, введите код или `?` для списка доступных кодов. Enter завершает программу после просмотра курсов.

## Пять полей ответа `latest`

| Поле | Значение |
| --- | --- |
| `base_code` | Код базовой валюты запроса. |
| `time_last_update_utc` | Время последнего обновления курсов в UTC. |
| `time_next_update_utc` | Запланированное время следующего обновления в UTC. |
| `rates.RUB` | Сколько российских рублей приходится на одну единицу базовой валюты. |
| `rates.USD` | Сколько долларов США приходится на одну единицу базовой валюты. |

В открытом API словарь курсов называется `rates`. [Документация ExchangeRate-API](https://www.exchangerate-api.com/docs/free)

## Проверка конвертации

1. Запустите программу и введите последовательно `USD`, `USD`, `RUB`, `100`. При первом запуске появится `Источник: API`.
2. Повторите те же действия. Должны появиться `Источник: кэш` и та же сумма с четырьмя знаками после точки.
3. Повторите оба запуска для `EUR`, `EUR`, `GBP`, `100`. После смены базы первый запуск получит данные из API, следующий прочитает кэш.

Для произвольной пары программа делит сумму на курс исходной валюты и умножает на курс целевой, поэтому обе валюты можно пересчитать по одному набору курсов.

Курсы предоставлены [ExchangeRate-API](https://www.exchangerate-api.com).
